# Results Directory

This directory is reserved for output files generated by the adipose scRNA-seq analysis workflow.

Generated results are not included in this GitHub repository because they may contain large files, intermediate R objects, manuscript-specific outputs, or unpublished analysis results. The purpose of this directory is to document the expected local output structure.

## Expected local output structure

Running the analysis scripts locally will generate a structure similar to:

```text
results/
├── README.md
├── qc/
├── integration/
├── annotation/
├── major_celltype_DE/
├── aspc_subcluster/
├── ec_subcluster/
├── macrophage_subcluster/
├── cellchat_major/
└── cellchat_subcluster/
```

Each script creates its own output directory automatically if it does not already exist.

## Output folders

### `qc/`

Generated by:

```text
scripts/01_quality_control.R
```

This folder contains quality-control outputs generated for each sample.

Expected outputs include:

```text
qc_summary.csv
session_info_QC.txt
before_filtering/
after_filtering/
```

Typical contents include:

- QC summary table
- Histograms and violin plots for detected genes, UMIs, mitochondrial percentage, and library novelty
- Session information for the QC step

## GitHub results policy

The `results/` directory is included only to document the expected local output structure.

Generated result files should not be committed to GitHub, including:

```text
*.rds
*.RDS
*.RData
*.csv
*.tsv
*.xlsx
*.pdf
*.png
*.jpg
*.jpeg
*.txt
```

These files are excluded through `.gitignore` to avoid uploading large intermediate objects, unpublished result tables, or manuscript-specific outputs.

The public repository is intended to document the analysis workflow rather than store generated results.

---

## Re-running the workflow

To regenerate local results, run the scripts in order:

```text
scripts/01_quality_control.R
scripts/02_integration.R
scripts/03_clustering_annotation.R
scripts/04_major_celltype_DE_analysis.R
scripts/05_aspc_subcluster_analysis.R
scripts/06_endothelial_subcluster_analysis.R
scripts/07_macrophage_subcluster_analysis.R
scripts/08_cellchat_major_celltype_analysis.R
scripts/09_cellchat_subcluster_analysis.R
```

Outputs will be generated under the corresponding subdirectories in `results/`.
