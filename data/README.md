# Data Directory

This directory is reserved for input data used by the adipose scRNA-seq analysis workflow.

Large data files are not included in this GitHub repository. Raw count matrices, processed count matrices, and Seurat objects should be stored locally or obtained from the associated public data repository, such as GEO, once available.

## Local data structure

The analysis scripts expect local data to be organized in a structure similar to:

```text
data/
├── README.md
├── F1/
│   ├── barcodes.tsv.gz
│   ├── features.tsv.gz
│   └── matrix.mtx.gz
├── F2/
│   ├── barcodes.tsv.gz
│   ├── features.tsv.gz
│   └── matrix.mtx.gz
└── processed/
    ├── Sample_01_filtered_seurat.rds
    ├── Sample_02_filtered_seurat.rds
    └── ...
```

The folder names shown above are examples. In the public workflow scripts, sample names are written as placeholders such as `Sample_01` and `Sample_02`.

## Raw count matrices

Each sample directory should contain the standard 10x Genomics matrix files:

```text
barcodes.tsv.gz
features.tsv.gz
matrix.mtx.gz
```

These files are used by `Read10X()` in Seurat.

## Processed Seurat objects

QC-filtered Seurat objects generated by `scripts/01_quality_control.R` can be saved locally under:

```text
data/processed/
```

Example processed files:

```text
data/processed/Sample_01_filtered_seurat.rds
data/processed/Sample_02_filtered_seurat.rds
```

These processed objects are used as input for `scripts/02_integration.R`.

## GitHub data policy

The `data/` directory is included only to document the expected local data structure.

The following files and folders should not be committed to GitHub:

```text
data/F1/
data/F2/
data/raw/
data/processed/
*.rds
*.RDS
*.RData
*.mtx
*.mtx.gz
*.tsv.gz
*.h5
*.h5ad
```

These files are excluded through `.gitignore` to avoid uploading large or unpublished data.

## Data availability

Raw and processed scRNA-seq data will be available through the associated public data repository once released.
