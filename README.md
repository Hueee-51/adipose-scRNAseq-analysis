# Adipose scRNA-seq Analysis

This repository contains the public analysis workflow for single-cell RNA sequencing (scRNA-seq) analysis of adipose tissue under diet-induced metabolic stress.

The code documents the major computational steps used in the study, including quality control, sample integration, major cell type annotation, cell type-specific differential expression analysis, ASPC/endothelial/macrophage subcluster analysis, pathway analysis input generation, and CellChat-based cell-cell communication analysis.

Large sequencing files, processed Seurat objects, intermediate R objects, and manuscript-specific figure styling scripts are not included in this repository.

## Analysis workflow

### 1. Quality control

**Script:** `scripts/01_quality_control.R`

This script loads raw or processed 10x Genomics count matrices, creates Seurat objects, calculates quality-control metrics, filters low-quality cells, and saves QC-filtered Seurat objects for downstream analysis.

Main QC metrics include:

- Number of detected genes
- Number of UMIs
- Mitochondrial read percentage
- Library novelty

Key filtering parameters are documented in `config/analysis_parameters.yaml`.

---

### 2. Sample integration and clustering

**Script:** `scripts/02_integration.R`

This script integrates QC-filtered Seurat objects using an SCT-based Seurat integration workflow.

Main steps include:

1. Loading QC-filtered Seurat objects
2. SCTransform normalization for individual samples
3. Selection of integration features
4. SCT integration
5. PCA and UMAP dimensionality reduction
6. Graph-based clustering
7. Cluster marker identification

The integrated object generated by this step is used for major cell type annotation.

---

### 3. Major cell type annotation

**Script:** `scripts/03_clustering_annotation.R`

This script annotates integrated Seurat clusters into major cell types based on canonical marker gene expression and cluster-level marker analysis.

Major cell types include:

- ASPC
- Endothelial Cell
- Macrophage
- B Cell
- T Cell
- Mesothelial Cell
- Dendritic Cell
- Neutrophil

Clusters sharing the same canonical marker profile were merged into biologically interpretable major cell types. The annotation table in this script records the final annotation used for the manuscript analysis. Cluster IDs may vary if the workflow is rerun independently under different package versions or parameter settings.

Representative marker genes used to guide annotation include:

| Cell type | Representative markers |
|---|---|
| ASPC | `Pdgfra`, `Dpp4`, `Ly6a` |
| Endothelial Cell | `Pecam1`, `Cdh5`, `Kdr` |
| Macrophage / Myeloid | `Ptprc`, `Lyz2`, `Adgre1`, `Mafb` |
| T Cell | `Cd3d`, `Cd3e` |
| B Cell | `Ms4a1`, `Cd79a` |
| Mesothelial Cell | `Msln`, `Wt1` |
| Dendritic Cell | `Flt3`, `Itgax` |
| Neutrophil | `S100a8`, `S100a9` |

### 4. Major cell type-level differential expression analysis

**Script:** `scripts/04_major_celltype_DE_analysis.R`

This script performs differential expression analysis between experimental conditions within each annotated major cell type.

The main comparison is:

```text
HFSC vs Chow
```

Differential expression analysis is performed within each major cell type using Seurat’s `FindMarkers` function.

Outputs include:

- Cell type-specific DE tables
- Combined DE table across major cell types
- Filtered DEG table
- IPA input tables

The filtered DEG table is intended for downstream pathway analysis input.

---

### 5. ASPC subcluster analysis

**Script:** `scripts/05_aspc_subcluster_analysis.R`

This script subsets ASPCs from the annotated Seurat object and performs independent reprocessing and reclustering to resolve ASPC subpopulations.

Main steps include:

1. Subsetting ASPCs
2. SCT-based reintegration and reclustering
3. ASPC subcluster marker identification
4. ASPC subcluster annotation
5. Subcluster composition analysis by condition
6. Subcluster-level differential expression analysis
7. Export of pathway analysis input tables

ASPC subclusters used in the analysis include:

- Areg
- FAP
- ASC
- PreA
- RMP

Unassigned clusters were excluded from downstream ASPC subcluster analysis.

---

### 6. Endothelial cell subcluster analysis

**Script:** `scripts/06_endothelial_subcluster_analysis.R`

This script subsets endothelial cells and performs independent reclustering to resolve endothelial subpopulations.

Main steps include:

1. Subsetting endothelial cells
2. SCT-based reintegration and reclustering
3. Endothelial subcluster marker identification
4. Endothelial subcluster annotation
5. Subcluster composition analysis by condition
6. Subcluster-level differential expression analysis
7. Export of pathway analysis input tables

Endothelial subclusters used in the analysis include:

- REC: Resting Endothelial Cells
- IREC: Immune-responsive Endothelial Cells
- IEC: Inflammatory Endothelial Cells
- VEC: Vascular Endothelial Cells
- MbEC: Metabolic Endothelial Cells
- MesEC: Mesenchymal-like Endothelial Cells

Unassigned clusters were excluded from downstream endothelial subcluster analysis.

### 7. Macrophage subcluster analysis

**Script:** `scripts/07_macrophage_subcluster_analysis.R`

This script subsets macrophages and performs independent reclustering to resolve macrophage subpopulations.

Main steps include:

1. Subsetting macrophages
2. SCT-based reintegration and reclustering
3. Macrophage subcluster marker identification
4. Macrophage subcluster annotation
5. Subcluster composition analysis by condition
6. Subcluster-level differential expression analysis
7. Export of pathway analysis input tables

---

### 8. Major cell type-level CellChat analysis

**Script:** `scripts/08_cellchat_major_celltype_analysis.R`

This script performs CellChat analysis using annotated major cell types.

Main steps include:

1. Splitting the annotated Seurat object by condition
2. Creating CellChat objects for Chow and HFSC groups
3. Using the mouse CellChat database
4. Restricting analysis to secreted signaling interactions
5. Inferring ligand-receptor communication probabilities
6. Aggregating communication networks
7. Comparing global interaction number and interaction strength
8. Exporting ligand-receptor and pathway-level communication tables

Selected pathways examined include:

- COMPLEMENT
- CCL
- ANGPTL
- MIF
- TGFb

---

### 9. Subcluster-level CellChat analysis

**Script:** `scripts/09_cellchat_subcluster_analysis.R`

This script performs CellChat analysis at the subcluster level by combining ASPC, endothelial, and macrophage subcluster annotations with the major annotated Seurat object.

Main steps include:

1. Loading major cell type and subcluster-annotated Seurat objects
2. Merging subcluster annotations into the major object
3. Creating a unified `cellchat_group` metadata field
4. Running CellChat separately for Chow and HFSC groups
5. Comparing communication networks between conditions
6. Exporting ligand-receptor and pathway-level communication tables

This analysis provides higher-resolution cell-cell communication information across biologically annotated subpopulations.

## Reproducibility notes

This repository provides a public workflow skeleton and documents the analysis logic used in the study.

Because Seurat clustering results can depend on software versions, package updates, random seeds, and preprocessing details, exact cluster IDs may not be identical if the full workflow is rerun independently. Final cell type and subcluster annotations were assigned based on canonical marker gene expression and cluster-level marker analysis.

Publication-quality figure styling, exploratory visualization code, local file paths, large intermediate objects, and manuscript-specific figure adjustments are not included.
